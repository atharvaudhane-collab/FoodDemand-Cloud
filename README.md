# FoodDemand Cloud



Cloud-Based Food Order Demand Prediction System using Machine Learning and AWS.



## Live Dashboard



[Click Here to Open FoodDemand Dashboard](http://32.236.226.74:5000)



## Project Features



- Food Demand Prediction

- Food Item and Price Input

- Previous Demand Input

- Promotion Selection

- Temperature Input

- Prediction Result

- Prediction History



## Technologies Used



- Python

- Flask

- Pandas

- Scikit-learn

- Joblib

- Amazon EC2

- AWS Systems Manager



## Project Files



- app.py

- model.py

- train_model.py

- create_dataset.py

- food_demand_dataset.csv

- food_demand_model.pkl



## Run Locally



Run `python app.py` and open http://127.0.0.1:5000.
